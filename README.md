# hw2 · Obama corporation

Навчальний репозиторій команди Obama corporation для практичних робіт з безпеки застосунків (DevSecOps). Код навмисно містив уразливості й призначений лише для навчання

## Команда

PO · QA · Dev · DevOps

## Роботи

**SAST** — статичний аналіз коду, автоматична перевірка в CI, виправлення знайдених уразливостей.

**DAST** — динамічне сканування сторінки входу OWASP Juice Shop (варіант 2), збирання контейнера, сховище артефактів і SBOM.

## Інструменти

| Призначення | Інструмент |
|---|---|
| Статичний аналіз коду | Semgrep |
| Динамічне сканування | OWASP ZAP |
| CI/CD | GitHub Actions |
| Контейнер | Docker |
| Сховище артефактів | GitHub Container Registry |
| SBOM | CycloneDX, SPDX |
